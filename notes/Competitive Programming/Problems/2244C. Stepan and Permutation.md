```
Let p be a permutation of length n, and given x, y such that x + y <= n. 
In one operation you can pick indices i, j such that at least |i-j| = x or |i-j| = y and swap p_i and p_j. Can you sort the array?
```

```
Solution: 
- Let g = gcd(x, y)
  
- Let a, b be the number of swaps we perform with condition (1) and (2) respectively then the final position p_final = p_current + x*a + y*b.
   
- By Benzout's Theorem, there should be a, b such that 
p_final = p_current + g => p_final mod g = p_current mod g, 
Therefore all elements whose positions are congruent to each other mod g can be interchanged. 
  
- Check that p_i is congruent to i (mod g). 
```
