```
Problem: 
You have an Nx3 grid and you want to paint each cell exactly one of three colors: Red, Yellow, or Green while making sure that no two adjacent cells have the same color. Given n number of rows, what is the number of ways to paint the grid (mod 1e9+7)
```

```markdown
**Answer:** 
For each row there we could have the following arrangements: 
[A, B, A] -> # ways = 3 . 2 = 6
[A, B, C] -> # ways = 3! = 3 . 2 = 6

Let a[n] be #ways to color starting with 2 colors, and b[n] be #ways to color starting with 3 colors. Then dp[n] = a[n] + b[n]; We can also see that a[1] = 6, and b[1] = 6;

Starting with 2 colors, the next possible arragement can be two colors or three colorsz; 

row k   [A, B, A]
row k-1 [B, A, C] or [C, A, B] OR [B, C, B], [C, A, C], [B, A, B]

so a[k] = 2b[k-1] + 3a[k-1]; 

Starting with 3 colors: 
row k   [A, B, C]
row k-1 [B, A, B], [B, C, B] OR [B, C, A], [C, A, B]

so b[k] = 2a[k-1] + 2b[k-1];
DP transition: dp[k] = a[k] + b[k];
```

```c++
// There should be a faster way of doing this using closed form solution by solving the recurrence relation

std::vector<int> a(n+1), b(n+1); a[1] = 6; b[1] = 6; 
std::vector<int> dp(n+1);
for(size_t i = 1; i <= n; i++) { 
	a[i] = (2 * b[i-1]) % MOD + (3 * a[i-1]) % MOD; 
	b[i] = (2 * a[i-1]) % MOD + (2 * b[i-1]) % MOD; 
	dp[i] = (a[i] + b[i]) % MOD; 
}
std::cout << dp[n] << "\n";
```
