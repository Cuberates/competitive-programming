## Competitive Programming Archive

- This repository contains solution files for programming contests and essential files for programming competitions. The competitions range from ICPC Regionals and Codeforces Weekly Contests to HackerRank/LeetCode problem implementations. I plan to add a few directories containing debugging templates for dynamically outputting data structures and code snippets for well-known structures and algorithms to save time during competitions.

- **Cleaning build and test artifacts**
  - Run `make clean-preview` to list candidates, then `make clean` to remove `*.bin*`, `*.out`, `*.in`, `*.o`, `*.obj`, and `*.exe` files throughout the repository. Input files (`*.in`) are included, so check the preview if you keep sample inputs.
  - Cleanup skips all hidden files and directories, including nested `.git`, `.github`, `.cph`, and `.vscode` data. C++ sources, headers, Typst notes, PDFs, Markdown, and images are preserved. Other filenames, including extensionless executables, are left alone.
